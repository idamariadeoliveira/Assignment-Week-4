# Assignment-Week-4
'Assignment-Week-4' is part of the assessment for BIOS 640 – Introduction to Health Data Science Methods.

## Overview

This repository contains the complete work for **Assignment Week 4** of BIOS 640. Building upon data cleaned in Assignments week 2 and visual analyses conducted in Assignments week 3, using R Markdown and version control via GitHub.

### Objectives & Contents
1. Exercise 1 - GitHub Repository Setup & Workflow
2. Exercise 2 - Customized R Markdown Report: Modification on report file from assignment of week 3 with advanced HTML output customization with tabbed figures, and interactive `DT` data viewer, through branch-based updates.
3. Exercise 3 - Dashboard: A `flexdashboard` featuring multi-row layouts.
4. Exercise 4 - Publication-Ready Tables: A narrative PDF report analyzing NHANES demographic and clinical data across waves with publication-ready LaTeX tables (`kableExtra`) and BibTeX citations.
